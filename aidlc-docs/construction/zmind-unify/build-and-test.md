# Zmind 提交入口统一 - 构建和测试指南

## 构建

### 前置条件
- Node.js 18+
- 已安装依赖：`npm install`
- 环境变量：`ZMIND_API_KEY`（或用户在个人中心配置）

### 构建步骤

```bash
# 1. 安装依赖（如有新增）
npm install

# 2. TypeScript 编译检查
npx tsc --noEmit --skipLibCheck

# 3. 构建前端
npm run build

# 4. 启动开发服务器验证
npm run dev
```

### 构建验证
- TypeScript 编译：✅ 零错误（已验证）
- 前端构建产物：`dist/` 目录
- 服务端启动：无报错

## 功能测试清单

### 测试 1: VersionIssueList — 描述模板统一
- [ ] 打开 QA 版本记录 → 点击"+ 提问题"
- [ ] 确认描述字段默认填充英文模板（Tested Environment / Operation Steps 等）
- [ ] 点击"套用 zmind 模板"按钮，确认模板正确

### 测试 2: VersionIssueList — 自定义字段全量显示
- [ ] 选择一个 zmind 项目
- [ ] 选择不同的 tracker
- [ ] 确认自定义字段不随 tracker 变化（始终显示项目下所有字段）
- [ ] 确认必填字段有 * 标记

### 测试 3: VersionIssueList — 附件上传到 zmind
- [ ] 启用"同步创建到 zmind"
- [ ] 选择项目，填写主题
- [ ] 点击"+ 选择文件"，添加 1-2 个文件
- [ ] 确认文件列表显示正确（文件名、大小、删除按钮）
- [ ] 点击提交
- [ ] 到 zmind 网页确认 issue 已创建且附件已关联

### 测试 4: CustomerProblemForm — 项目搜索树
- [ ] 打开问题追踪 → 添加客户问题/QA问题
- [ ] 启用"同步创建到 zmind"
- [ ] 确认项目列表显示层级关系（缩进 + ↳ 符号）
- [ ] 在搜索框输入关键词，确认过滤正确
- [ ] 选择一个子项目，确认选中状态显示

### 测试 5: CustomerProblemForm — 附件上传
- [ ] 启用 zmind 同步并选择项目
- [ ] 确认附件上传区域可见
- [ ] 选择文件，确认文件列表显示
- [ ] 删除一个文件，确认列表更新
- [ ] 提交表单
- [ ] 到 zmind 网页确认附件已上传

### 测试 6: CustomerProblemForm — 描述模板
- [ ] 启用 zmind 同步
- [ ] 清空描述字段
- [ ] 点击"套用 zmind 模板"
- [ ] 确认模板为英文版（与 VersionIssueList 一致）

### 测试 7: CustomerProblemForm — 自定义字段
- [ ] 选择项目后确认显示所有自定义字段
- [ ] 确认有 possibleValues 的字段渲染为下拉
- [ ] 确认无 possibleValues 的字段渲染为文本框/日期选择
- [ ] 确认必填字段有 * 标记

### 测试 8: 错误处理
- [ ] 不配置 zmind API Key，尝试上传附件，确认错误提示
- [ ] 上传超大文件（>500MB），确认错误提示
- [ ] zmind 服务不可用时，确认附件上传失败不阻塞 issue 创建

## 集成测试场景

### 场景 A: 完整 QA 版本问题提交流程
1. 进入 QA 版本记录
2. 点击"+ 提问题"
3. 选择 zmind 项目（使用搜索树）
4. 填写主题、描述（使用模板）
5. 选择 tracker、优先级、指派人
6. 填写自定义字段
7. 添加 2 个附件
8. 提交
9. **验证**: zmind 上 issue 创建成功，附件已关联，自定义字段正确

### 场景 B: 完整问题追踪提交流程
1. 进入问题追踪
2. 点击"添加 QA 问题"
3. 启用 zmind 同步
4. 选择项目（层级树）
5. 填写描述（使用模板）
6. 选择 tracker、优先级
7. 填写自定义字段
8. 添加 1 个附件
9. 提交
10. **验证**: zmind 上 issue 创建成功，附件已关联

### 场景 C: 两个入口一致性对比
1. 分别在两个入口选择同一个 zmind 项目
2. **验证**: 自定义字段列表完全一致
3. **验证**: 描述模板完全一致
4. **验证**: 项目树层级显示一致

## 已知限制

1. 附件上传依赖 zmind API Key 配置正确
2. 单文件最大 500MB
3. zmind 服务不可用时附件上传会失败（但 issue 仍可创建，只是不带附件）
4. 附件上传无进度条（逐个串行上传）
